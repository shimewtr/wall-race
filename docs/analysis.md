# AI・棋譜分析の観点と実験候補

この文書は、自己対戦ログと探索 AI から新しい戦術・特徴量・学習方法を見つけるための分析カタログ。
実験の確定結果は [roadmap.md](roadmap.md)、学習運用は [training.md](training.md) を正とし、ここでは「次に試せる分析」を広く管理する。

## 分析で守ること

- 探索上の評価差だけで結論を出さず、候補手ごとの終局結果も測る
- 敗戦だけでなく勝利・変化なしを対照群にする
- 2・3・4 手読みで傾向が残るか確認し、探索深度固有の癖を一般則にしない
- 同じ展開へ合流した局面は重複除去し、先後・世代・乱数を分けて再現確認する
- 手引き候補は全世代リーグ、AI 候補は400局以上の `compare.ts`、高速化はベンチのハッシュ一致で採否を決める
- 重い収集・対戦は GitHub Actions だけで行う

## 観点の洗い出し

### 1. 因果・反実仮想

現在の `counterfactual.ts` は、同じ局面で最初の1手だけを変え、その後を同じ探索 AI で指して勝敗差を測る。
今後は次も区別する。

- **深さ頑健性**: 追跡を2・3・4手読みに変えても改善する手か
- **相手頑健性**: 第12世代だけでなく、過去世代・手引き AI・深さ違いにも効くか
- **複数手介入**: 最初の1手だけでなく、最初の計画2手を固定すると勝敗が変わるか
- **寄与の時系列分解**: 各手を次善手に差し替え、どの手が最終勝敗へ最も寄与したか
- **半反実仮想**: 同じ手を続けても負けない最後の局面を探し、「ここから方針転換が必要」という境界を出す

反実仮想で劇的に結果が変わるエピソードを抽出する考え方は、オフポリシー評価の研究でもデバッグ用途として提案されている。

### 2. 近傍局面・境界分析

発見した局面をそのまま規則化せず、合法性を保った小さな編集を加える。

- コマを最短路上で1マス前後させる
- 残り壁を1枚増減する
- 既存の壁を1アンカーずらす、向きを変える、1枚だけ除く
- 手番を入れ替える

どの最小変更で最善手・勝敗・評価順位が変わるかを見る。これにより「残り5歩」のような見かけの相関ではなく、判断境界を特定できる。生成した局面は必ず到達可能性と合法性を確認する。

### 3. 対称性・メタモルフィックテスト

ルール上等価な局面で AI の判断も等価かを調べる。

- 左右反転した局面では、選ぶ手と評価値も左右反転するか
- プレイヤーを交換して上下反転した局面で結果が一致するか
- 同じ盤面へ別の棋譜で到達したとき、直近マス以外の判断が変わらないか

不一致があれば新戦術ではなく、候補順・キャッシュキー・同点処理・履歴依存の偏りである可能性が高い。大量対局より先に行える、費用の低い健全性検査でもある。

### 4. 読みの深さによる判断反転

同じ局面を1〜4手読みで評価し、次を記録する。

- 最善手が初めて変わる深さ
- 前進↔壁、壁の向き、壁の位置がどう変わるか
- 深く読むほど評価が上がる手と下がる手
- 3手と4手で勝敗予測が逆転する局面

「浅い探索では見えず、深い探索で現れる概念」を集める。AlphaZero/Hex の分析でも、探索が内部モデルより先に概念を発見する場合が報告されており、このプロジェクトではニューラルネットの代わりに静的評価と探索の差として直接測れる。

### 5. 手順モチーフ・局面クラスタリング

単局面の特徴ではなく、前後の手順を短い記号列にする。

- 手の種類: 前進 / 横壁 / 縦壁
- 壁の役割: 即時遮断 / 守り / 連結 / 相手に壁を返させる
- 壁の位置関係: 接続 / 平行 / T字 / 離れた封鎖
- 形勢の遷移: 先着可能→不可能、壁脅威増減、残り壁差
- 応手: 相手が前進したか、壁で返したか

3〜8手程度のモチーフでクラスタ化し、勝敗を改善した群の代表局面（medoid）と似ているが改善しなかった対照局面を並べる。平均値だけより「この並びのときだけ有効」という戦術を発見しやすい。軌跡を方策ごとにクラスタ化する研究も、複数の行動様式が混在するデータの構造化に使われている。

### 6. 概念プロトタイプ発見

人間が理解できる候補概念を先に固定せず、勝敗を変えた局面の共通部分を探す。

1. 決定的局面を盤面・数値・直後の手順でベクトル化する
2. 類似局面をまとめ、各クラスタの代表例と反例を選ぶ
3. LLM が「長い横壁を作る」「出口を片側に寄せる」など仮の名前を付ける
4. 名前に対応する計測可能な条件を実装する
5. 別シード・別世代で条件の精度を再確認する

AlphaZero のチェス研究では、概念の代表局面と反例を抽出して、人間のトッププレイヤーが学べる形へ移す方法が示されている。このプロジェクトでは `guide.md` に載せられる具体例まで作ることを出口にする。

### 7. 小さな決定木・ルールへの方策蒸留

探索 AI の判断を、解釈可能な浅い木へ近似する。

- 入力: 残り歩数、壁枚数、壁脅威、連結壁効果、経路本数、局面フェーズなど
- 出力: 前進 / 壁、壁の向き、候補壁間の選択
- 学習対象: 全局面ではなく、手引きと探索 AI が不一致かつ勝敗に影響した局面を重くする
- 評価: 探索 AI への一致率だけでなく、蒸留ルール自身を全世代リーグで対戦させる

木全体をそのまま採用するのではなく、精度が高く短い枝を戦術候補として取り出す。RL 方策を決定木へ蒸留して解釈可能にする研究があり、現在の手作業による複合条件探索を体系化できる。

### 8. 特徴量の寄与・相互作用

新特徴量を足す前に、既存特徴量がどの局面で効いているかを測る。

- **leave-one-out**: 1特徴だけ重み0にして、選択手が変わる局面と勝率を測る
- **符号反転・局所摂動**: 重みを±10〜25%動かし、判断が敏感な局面を抽出する
- **二要因相互作用**: `netWallThreat × wallChain` のように、片方だけでは出ない効果を調べる
- **世代差分**: 世代ごとの重み差ではなく、その差で実際に選択手が変わった局面を追う
- **特徴量の重複**: 2つの特徴が同じ局面で同時に増減する比率を測り、二重評価を見つける

これまで不採用になった `wallRescue` や `wallExtension` は、既存の壁関連特徴との重複を事前に測ることで、400局比較へ進む候補をさらに絞れる。

### 9. 評価値の校正と不確実性

総合勝率だけでなく、評価値が外れる局面を探す。

- フェーズ、残り壁、歩数差、手番別に評価値→実勝率を校正する
- 予測50%付近だけでなく、自信80%以上なのに負ける局面を優先分析する
- 3手と4手の評価差を不確実性の代理値にする
- 同じ局面から序盤乱数や相手世代を変えた複数追跡で、勝敗分散を測る

「評価値は高いが方策に依存して不安定な局面」と「どの相手にも安定して勝つ局面」を分けると、誤った特徴量候補を減らせる。

`calibrate.ts` を拡張し、第12世代の独立800局を前半400局の当てはめと後半400局の検証に分けて調べた。

- 10%刻みの予測は実勝率と概ね一致した。条件別の平均差は、序盤が45.0%→50.0%（+5.0pt）、終盤が52.1%→49.0%（-3.0pt）、2歩以上先行が75.3%→80.0%（+4.7pt）で、この3条件のずれが比較的大きかった
- 高信頼（80%以上）で外したのは867/32,830局面（2.6%）、188/400対局。終盤は686件で局面数に対して6.1%、中盤1.0%、序盤0.3%と、終盤へ強く集中した
- 盤上の残り壁14〜20枚では高信頼誤予測が579/10,578局面（5.5%）、7〜13枚で2.2%、0〜6枚で0.9%。多くの壁を残したままゴールへ近づいた局面は、現在の評価が大差でもその後の壁応酬で逆転しやすい
- `myWalls` 除外後の換算係数は全800局で `a=0.03020, b=-0.2813`。除外前に作られたWeb用の係数 `a=0.02056, b=0.1097` は評価尺度と合わないため更新した
- 盤上の残り壁とゴールまでの近さを「予測の不確実性」とし、スコアとの交互作用を持つ校正式を別seedの前半400局で学習、後半400局で検証した。全局面のBrier scoreは0.1636→0.1548、log lossは0.4819→0.4547。高不確実性局面では0.2688→0.2298、0.7498→0.6439と改善したため、評価関数の重みは変えずWebの勝率表示へ採用した
- `confidence-errors.ts` で、高信頼誤予測を1対局1件・同一盤面1件に絞り、フェーズ・壁量・不確実性・手数・自信度を合わせた正解局面と比較した。独立1,600局から誤予測120局面を取ると、3→4手の判断変更は誤予測19/120（15.8%）、対照11/120（9.2%）だった
- 判断が変わった19局面を各20回追跡すると、3手の手59.7%、4手の手64.2%（+4.5pt）だったが、局面単位では改善9・悪化7・同じ3。初回800局の重複除外後20局面で得た+7.0pt、改善12・悪化5より弱く、適応的4手読みを採用する根拠にはしない
- 文脈付き校正後に残った誤予測は中盤65・終盤55、盤上の残り壁0〜6枚が80/120で、形勢反転まで平均14.0手。直近の戦術だけでなく長い方策依存が大きく、4手読みだけでは解消しない
- 優勢評価側の壁不足は誤予測46.7%、対照35.8%、2枚以上不足は25.8%対16.7%だった。この仮説を `calibration-wall-deficit.ts` で別seed評価すると、全体Brier scoreは0.1675→0.1666とごく小幅で、2枚以上不足時のlog lossは0.4485→0.4501へ悪化したため不採用
- `value-model.ts` で既存12特徴量の線形ロジスティック回帰と、各特徴量に盤上の総残り壁・ゴールへの近さを掛けた交互作用モデルをゲーム単位で学習/評価分割した。独立seed 2回で、現行校正→交互作用モデルの全体Brier scoreは0.1619→0.1602 / 0.1636→0.1590、log lossは0.4740→0.4712 / 0.4760→0.4664と小幅改善し、特に序盤・壁14〜20枚で再現した
- 2標本で係数の方向が安定した最大の関係は「壁が多い間は最短距離差を割り引く」だった。`pathDiff × (1 - 総残り壁/20)` を静的評価候補にし、重み5 / 2を現チャンピオンと各400局比較したが47.3% / 47.5%で不採用。勝敗予測の改善は、その特徴を探索の指し手選択へ入れれば強くなることを意味しない
- もう1つ両標本で安定した `wallDiff × |pathDiff|`（歩数差が大きいほど壁枚数差を重くする）も、重み1の初回400局は53.4%だったが、独立1,200局は48.0%、合計1,600局49.4%で再現せず不採用。交互作用モデルは高信頼誤りも初回1.8%→3.5%、再検証1.8%→2.1%と悪化したため、現時点ではWeb校正にもAI評価にも採用しない

### 10. 世代リーグ・非推移性

第1〜12世代の総当たり行列から、平均勝率だけでは見えないじゃんけん関係を調べる。

- 世代A>B、B>C、C>Aの循環
- 深さ2では勝つが深さ3では負ける組み合わせ
- 特定の壁戦術だけに弱い世代
- 単一チャンピオンではなく、過去世代の混合方策に対する強さ

学習相手の50%をチャンピオン、残りを過去世代としている現在の設計が、実際に非推移性を抑えているか確認できる。

`generation-league.ts` で第1〜12世代を3手読み・各組100局（合計6,600局）で総当たりさせた。

- 第12世代は過去11世代の全てに勝ち越し、平均63.9%で首位。最も近い第11世代にも55.0%で、最新世代だけが苦手とする過去世代は見つからなかった
- Bradley–Terryの1次元強さは第12世代+96、第11世代+90、第10世代+80 Eloの順。実測との残差RMSEは6.4%で、最大残差は主に第1〜3世代間だった
- 95%区間でも旧世代が新世代へ勝ち越したのは第2世代対第3世代の64.0%だけ。初期の世代には単調でない部分があるが、最近の学習を脅かす規模ではない
- 初回に第4→第5→第9→第4の循環が見えたが、別シード・各組400局で再検証すると第5→第4が55.5%、第9→第5が55.0%、第9→第4が62.0%となり、循環は再現しなかった
- 現時点では非推移性対策として学習相手の配分を変更しない。次は評価値の校正をフェーズ・壁数・歩数差に分解し、高信頼の誤予測局面を探す

### 11. 苦手局面から始める重点学習

現在の自己対戦は初期局面から始めるため、決定的だが出現頻度の低い中終盤へ届くまで多くの計算を使う。

- 反実仮想で勝敗が変わった局面
- 3手と4手で判断が割れる局面
- 評価値の自信が高いのに負けた局面
- 世代間で最善手が割れる局面

これらを「局面アーカイブ」に保存し、一部の学習対局をそこから開始する案がある。AlphaZero 系でも、関心のある中間局面から自己対戦を始める search control が、Connect Four と9×9 Goで標本効率を改善したと報告されている。ただし通常の初期局面分布へ過適合しないよう、まず独立した Experiment で比較し、採用時も開始局面の比率を制限する。

### 12. 手引きとしての価値

強いが説明困難な規則と、少し弱くても人間が再現できる規則を分けて評価する。

- 数える量の数: 残り歩数、壁枚数など何項目必要か
- 読む手数: 0〜2手で実行できるか
- 候補壁の数: 全合法手ではなく盤面上で数個に絞れるか
- 例外数: 条件分岐が何個あるか
- 全世代リーグ勝率との Pareto 前線

「AI特徴量として不採用」でも、代表局面を使った人間向けの注意点として価値が残る場合がある。連結壁はこの扱いが適している。

## 優先順位

### 優先 A: 安く、誤分析を減らす

1. `symmetry.ts`: 左右反転・上下プレイヤー交換で、合法手・手・評価値の等価性を検査する（実装・初回分析済み。下記参照）
2. `horizon.ts`: 同じ局面を1〜4手で読み、最善手・評価・手の種類が反転する深さを集計する（実装・初回分析済み。下記参照）
3. `ablation.ts`: 既存特徴量を1つずつ0にし、選択手変更率・深さ依存局面への集中・特徴間の重複を測る（実装・初回分析済み。下記参照）

### 優先 B: 新戦術を見つける

4. `motifs.ts`: 決定的局面の前後8手を記号化し、改善群と対照群の頻出手順を比較する（実装・独立2標本の初回分析済み。下記参照）
5. `boundaries.ts`: 決定的局面へ合法な最小編集を加え、最善手が変わる境界を探す（既存壁1枚の除去・残り壁の分離と独立2標本の分析済み。下記参照）
6. `distill.ts`: 深さ2〜3の小さな決定木・ルールリストを作り、未知シードで精度を測る（実装・初回分析済み。下記参照）

### 優先 C: 学習方法を変える

7. 決定的局面アーカイブを作る（`archive.ts` 実装・初回収集済み。下記参照）
8. 対局の10〜20%だけアーカイブ局面から開始する候補を、通常学習と独立比較する（`archive-training.ts` 実装・予備比較済み。改善信号なしで不採用）
9. 改善が確認できた場合だけ Train の学習分布へ入れる（予備比較で改善しなかったため進めない）

### 優先 D: 学習の盲点を調べる

10. `generation-league.ts`: 歴代世代の総当たりと非推移性を調べる（実装・初回総当たり・循環候補の独立再検証済み。最近の世代に再現する循環なし）
11. `calibrate.ts` を拡張し、フェーズ・残り壁・歩数差ごとの校正誤差と、高信頼で外した局面を抽出する（実装・独立800局の分析済み。終盤かつ壁が多い局面へ誤予測が集中）
12. 残り壁とゴールまでの近さを不確実性項として校正式へ加え、独立標本のBrier scoreとlog lossで単純な式と比較する（実装・独立800局で改善確認・Web表示へ採用済み）
13. `confidence-errors.ts`: 高信頼誤予測と条件を合わせた正解局面を比較し、4手読みの判断を反実仮想追跡する（実装・独立再検証済み。4手側の改善が安定せず不採用）
14. 優勢評価側の壁不足を追加の不確実性として検証する（`calibration-wall-deficit.ts` 実装・独立評価済み。改善が小さく一部指標悪化で不採用）
15. `value-model.ts`: 既存特徴量の小さな非線形価値モデルをゲーム単位の独立標本で比較する（実装・独立2標本で予測改善を確認。ただし距離差×壁減少の評価特徴は各400局で負け越して不採用）

## 対称性分析の結果

- 第12世代・3手読み・120局面で、合法手集合は左右反転・上下反転＋プレイヤー交換とも全件一致した
- 旧探索では評価値が左右9件、上下4件で不一致、選択手も左右2件で不一致だった
- `wallChain` を0にすると評価値の不一致が全て消えた。原因は即時効果が同率の1枚目を盤面走査順で選び、反転時に別の2枚目を評価していたこと
- 攻撃側から見た盤面を上下・左右に正規化して同率候補を選ぶよう修正後、評価値は240比較すべて一致。左右1件だけ評価値が完全同値の別手を選んだ
- 旧方式との400局比較は **49.5% ±4.9** で互角。3手読みは新10.3ms/手・旧7.9ms/手、4手読みは新31.9ms/手・旧27.8ms/手。正しさの修正として許容し採用した
- 全同率候補を読む方式も試したが、3手読みが14.5ms/手まで悪化したため不採用

## 読み深さ分析の結果

- 第12世代の120局面では、最善手の変更率が1→2手で20.8%、2→3手で9.2%、3→4手で11.7%だった
- 3→4手で変わった14局面の内訳は、前進→壁6、壁→前進2、壁の向き変更3、別の壁1、別の移動先2。深読みで壁へ切り替わる方向がやや多い
- 3手読みから4手読みまで同じ手だったのは106/120（88.3%）。一度変えて元へ戻る局面は8/120、1=3手・2=4手の厳密な偶奇振動は3/120
- 3→4手の変更率は序盤13.3%、中盤17.9%、終盤8.1%。変更局面は平均で自分あと7.1歩・相手あと6.4歩、双方の壁が約6枚で、壁の応酬が残る中盤ほど深さの影響が大きい
- 平均探索ノードは1手10.6、2手44.8、3手219.3、4手690.1。3→4手は約3.1倍
- 生の評価値は `myWalls` など深さの偶奇で基準がずれる項を含むため、異なる深さ間の符号反転を勝敗反転とは扱わない。以後は選択手の変更を主指標にする

## 特徴量アブレーションの結果

- 第12世代・3手読み・120局面で、重みを0にしたときの最善手変更率は `urgency` 36.7%、`wallDiff` 35.0%、`pathDiff` 25.8%が上位。この3特徴が現在の方策の骨格になっている
- 壁関連では `wallsWhenClose` 14.2%、`wallThreat` 11.7%、`netWallThreat` 6.7%、`wallChain` 5.8%。`netWallThreat` が変えた8局面は全て `wallThreat` の変更局面に含まれ（Jaccard 0.57）、うち5局面は `wallChain` とも重なったため冗長性を400局比較で確認する
- `adjacent` は0/120、`lockedRace` は1/120、`center` は2/120でしか手を変えなかった。低頻度でも終盤などで効く可能性があるため、即削除せず対戦で確認する
- `myWalls` は平均評価差19.35と大きい一方、手を変えたのは4/120。現行対重み0は別シード各400局で52.0%と48.0%、合計800局50.0%だった。強さへ寄与せず候補手共通の評価オフセットとして読み深さ間の生スコア比較を歪めるため、評価・学習対象から外した（既存JSONの値は互換性のため残っていても無視する）
- `myWalls` 無効化後に horizon を再実行すると、3→4手の最善手変更は14/120のまま、厳密な偶奇振動は3→1局面、生評価の符号反転は40.0%→29.2%になった。対局展開自体が変わるため同一標本の因果比較ではないが、不要なオフセットを除いた方向と整合する
- 深さ依存13局面のうち、`urgency` と `pathDiff` は各9局面、`wallThreat` は5局面、`netWallThreat` は4局面で判断を変えた。深読みで変わる局面は距離と壁脅威の相互作用を優先して調べる

## 手順モチーフ分析の結果

- `motifs.ts` で駒手を最短距離が縮む・同じ・延びる、壁を横/縦・即時の正味効果・既存壁への連結に記号化し、判断点の前後各4手を比較できるようにした
- 独立シード各600局面で3手→4手の最善手変更は79件（13.2%）と66件（11.0%）。中盤は18.8%と22.8%で、両標本とも序盤・終盤より高かった
- 深読みで「前進→有利な横壁」へ変わる型が16件と17件で最多。前進から何らかの壁へ変わったのは32件と28件で、3手読みは壁を置く時機を遅く見積もりやすい
- 実際のその後に `P+ P+ H+`（双方が前進してから有利な横壁）が現れる比率は、初回が変更14/79・安定6/521（平滑化比13.84倍）、独立標本が変更10/66・安定10/534（7.88倍）。判断点を含む `P+ | P+ P+ H+` も24.21倍と9.63倍で再現した
- 細かい壁の向きの連続は標本間で上位が入れ替わったため、現時点では一般則にしない。次は `boundaries.ts` で該当局面の壁を1枚ずつ除く最小編集を行い、どの壁配置が「今進むか、今横壁を置くか」の境界を作るか調べる
- 同じ対局から複数局面を採る探索的相関であり、特徴量の採用根拠ではない。境界分析で盤面条件を絞った後、別シードと400局比較で検証する

## 判断境界分析の結果

- `boundaries.ts` で既存壁を1枚選び、(1)盤面から除くだけ、(2)持ち主の残り壁を1枚増やすだけ、(3)両方、の3介入に分けた。これにより、過去にその壁を置かなかった反実仮想を、盤面形状と壁枚数へ分解した
- 独立シードの変更局面26件 / 31件では、形状だけの編集で3手・4手の不一致が消えた局面が21件 / 24件、残り壁だけでは7件 / 10件。深さ依存の主因は壁枚数より盤面の経路形状だった
- 不一致を解消した既存壁は、除いても不一致が残る壁より連結率が65.1%対50.0%、61.4%対52.7%と両標本で高かった。横壁率は69.2%対54.2%から68.0%対67.6%となり再現しなかったため、「横壁だから深読みが必要」とはしない
- 解消側の壁を除いたときの最短距離変化は、自分2.49・相手2.05歩 / 自分1.58・相手2.23歩。維持側の0.75・0.58歩 / 0.97・0.34歩より大きく、現在の経路が少数の既存壁へ強く依存する局面ほど深さに敏感という仮説が残った
- 次の `distill.ts` では、最大壁除去影響、影響のある既存壁数、連結率、残り距離・壁数などから、深読みが必要な局面を未知シードで識別できる小さな木を作る。これは探索深度を切り替える条件候補であり、勝率確認前に評価特徴へ足さない

## 深読み条件の蒸留結果

- 独立シード各800局面（学習の変更率9.6%、評価9.3%）で、3手と4手の最善手が変わるかを最大3段の均衡重み付き決定木へ蒸留した
- 基本量だけの木は未知シードでAUC 0.638、balanced accuracy 61.2%。経路の最大壁依存・影響壁数・依存合計・連結壁数を加えても同じ木になり、追加特徴は一度も選ばれなかった
- 最大4段・最小葉20へ広げると、基本量だけでAUC 0.681、balanced accuracy 64.2%。壁依存込みは連結壁数を末端で使ったがAUC 0.664、balanced accuracy 61.4%へ悪化した
- 基本量の木でも、危険度上位20%だけ4手読みして捕捉できる判断差は40.5%、上位30%で51.4%。計算を30%増やして約半数を見逃すため、適応的な4手読み条件には採用しない
- 学習標本では「盤上の壁13枚以下・7手目より後」や「盤上の壁14枚以上・自分が残り4歩以下・相手に壁が2枚以上」が高リスク葉になったが、未知標本で個別規則として検証していないため手引きや評価特徴にはしない
- 壁除去分析は深さ差を説明する局所反実仮想として有効だった一方、その要約値は未知局面の予測には不十分だった。次は予測器を複雑化せず、実際の深さ依存局面をアーカイブして重点学習の開始局面候補に使う

## 決定的局面アーカイブ

- `archive.ts` で自己対戦局面を収集し、3手と4手で最善手が違う局面を、盤面・残り壁・手番・棋譜・両探索の手/評価/ノード数とともに復元可能なJSONへ保存できるようにした
- 固定シードの1,200局面から重複のない108局面を収集した。序盤31・中盤42・終盤35で、終盤の長い棋譜だけに偏らないようフェーズ巡回で選んだ
- 判断の変化は前進→壁59、壁→前進24、別の前進13、壁の向き変更7、別の壁5。モチーフ分析と同じく、深読みで壁へ切り替える局面が最多だった
- 初回JSONはExperiment run `40101967637` のartifactに保存し、件数とスキーマを検証した。収集条件はスクリプトと固定シード97000000で再現できる
- `archive-training.ts` で同じ初期重み・摂動・対戦相手・乱数系列を使い、開始局面0% / 10% / 20%を各8反復×32組で予備学習した。独立評価各200局で、対チャンピオンの通常局面は51.7% / 49.5% / 49.0%、アーカイブ局面は全て50.0%、対初期重みは89.5% / 90.5% / 87.5%だった
- 10%・20%候補を0%候補と直接比べても、通常局面・アーカイブ局面とも全て50.0%。重みは初期値から0.071 / 0.076 / 0.107動いたが、短期では選択手の差として現れなかった
- 重点開始は通常分布も苦手局面も改善しなかったため、400局への拡大やTrain本体への接続は行わない。長期学習なら差が出る可能性は残るが、現時点では追加計算を正当化する予備信号がない

## 長期停滞時の学習再出発

- 第12世代への昇格後、約20,000反復・97判定を重ねても対チャンピオン48.0〜52.4%（平均50.7%）で昇格も47%未満のリセットも起きていない。学習率は開始時0.25から約0.075まで減衰し、現在位置の周辺を小さく動き続けている
- `restart-training.ts` で、現在位置と減衰済み学習率を使う `continue`、現在位置のまま学習率だけ戻す `reheat`、チャンピオンへ重みを戻して学習率も戻す `restart` を、同じ対戦相手・乱数・計算量で比較した。実験は `training/` を変更しない
- 12反復×3 seed×32組・各指標200局の予備比較は、対チャンピオンがcontinue 48.3%、reheat 48.5%、restart 50.2%。reheatはseed範囲43.0〜56.0%と広く、現在位置から大きく動かすだけでは不安定だった
- 独立seedでcontinueとrestartを各指標400局へ増やすと、対チャンピオンは50.1%対49.9%、対初期84.5%対85.8%、歴代混合64.5%対64.3%。restartの対チャンピオンseed範囲は49.8〜50.2%でcontinueの46.0〜53.8%より安定したが、強化の証拠はまだない
- 48反復×3 seedを1ジョブで回した初回は120分でタイムアウトし、結果を回収できなかった。同じコミット・条件を1 seedずつ3ジョブへ分割して再実行している。あわせて以後はseed×方式ごとにチェックポイントを保存し、タイムアウト後も残りから再開できるようにした
- 長期比較では安定性だけでなく学習後の伸びを測る。対チャンピオン・対初期・歴代混合を悪化させず複数seedで方向が一致した場合だけ、Trainへ停滞時リスタートを追加する

## 採否の目安

| 対象 | 次へ進む条件 |
| --- | --- |
| 相関・ルール候補 | 独立シードと3・4手読みの両方で方向が一致する |
| 手引き候補 | 全世代リーグ予備40局で現行を明確に上回り、100局で再確認する |
| AI特徴量 | 重み0でハッシュ一致。400局で52.5%以上なら追加標本、明確な勝ち越し後に学習対象へ入れる |
| 学習分布の変更 | 同じ計算量で対チャンピオン・対初期・過去世代混合の全てを悪化させない |
| 重い分析 | 新情報量が既存の `discover` / `counterfactual` を上回るか、先に小標本で確認する |
