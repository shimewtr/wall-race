# Wall Race

9×9 の盤で、壁を置いて相手の道をふさぎながら、自分のコマを向かい側の端まで先に運ぶ 2 人用ボードゲーム。ブラウザで遊べる。

人間向けの考え方の手順は [docs/guide.md](docs/guide.md)（自己対戦の分析と、手引きどおりに打つ AI の成績から作っている）。

## 遊び方

```sh
npm install
npm run dev
```

- マスをクリック: コマを動かす（緑のマスが移動先）
- マスの間の溝をクリック: 壁を置く（スマホは 2 回タップで確定）

### ルール

- 自分のコマを、向かい側の端の列まで先に運んだら勝ち
- 手番では「コマを 1 マス動かす」か「壁を 1 枚置く」のどちらか
- 壁は 2 マス分の長さで、1 人 10 枚まで。重ねたり交差させたりはできない
- どちらかのゴールへの道を完全にふさぐ壁は置けない
- 相手のコマが隣にいたら飛び越えられる。後ろが壁や盤の端なら斜めに回り込める
- 300 手で決着しなければ引き分け（自己対戦用の安全装置）

## 構成

| パス | 内容 |
| --- | --- |
| `src/engine/game.ts` | ルールエンジン（DOM 非依存。ブラウザでも Node でも動く） |
| `src/engine/ai.ts` | 探索 AI（αβ 探索 + 反復深化）。評価関数は重みベクトル `Weights` |
| `src/web/` | ブラウザ UI。AI は Web Worker で動く |
| `scripts/arena.ts` | AI 同士を対戦させて勝率を出す |
| `scripts/train.ts` | 自己対戦で評価関数の重みを調整する（SPSA） |
| `training/` | 学習の状態。リポジトリで同期する（下記） |

## 棋譜表記

列 `a`〜`i`（左から）、行 `1`〜`9`（下から）。先手（青）は 1 段目から 9 段目を目指す。

- コマの移動: 移動先のマス（例: `e2`）
- 壁: 壁が接する 2×2 マスの左下のマス + `h`（横）/`v`（縦）（例: `e3h`）

## AI 同士の対戦

```sh
npm run arena -- --games 20 --a '{"maxDepth":3}' --b '{"maxDepth":2,"noise":2}'
```

`--a` / `--b` には `SearchOptions`（`maxDepth`, `timeMs`, `weights`, `noise`）を JSON で渡す。

## 学習

```sh
npm run train -- --minutes 30            # 30 分回して結果を push
npm run train -- --loop                  # 30 分ごとに push しながら回し続ける
npm run train -- --minutes 5 --no-sync   # git 操作なしで手元だけで試す
```

1. 学習中の重みを少し＋にずらした AI と－にずらした AI を、同じ相手（現チャンピオンか過去の世代）と同じ条件で 16 組ずつ対戦させ、勝率の差の方向へ重みを少し動かす（SPSA）。これを制限時間まで繰り返す
   - 学習・判定・Web の「つよい」はすべて 3 手読み。重みの良し悪しは読みの深さで変わるので、使う深さで鍛えて使う深さで判定する
   - 序盤 6 手は評価の上位 3 手からランダムに選ぶ。これが無いと自己対戦の序盤が毎回同じになり、特定の展開にだけ強い重みになる
   - ＋と－を直接戦わせると「すぐ隣の自分にだけ強い」方向へ流れる（じゃんけん型の堂々巡り）ので、相手は固定する
2. 終わったら最新を pull し、自分が進めた分の差分だけを最新の重みに足し込む（Mac と GitHub Actions で同時に回しても進捗が消えない）
3. 現チャンピオン・初期の重みとそれぞれ 400 局対戦し、次をすべて満たせば新しい世代に昇格
   - 対チャンピオンの勝率 55% 以上
   - 対初期の勝率がチャンピオンより 3 ポイント以上下がっていない（特定の相手にだけ強い、を防ぐ）
4. 対チャンピオンの平均勝率が 47% 未満なら、学習中の重みをチャンピオンの重みに戻してやり直す
5. `training/` を commit して push（競合したら 2 からやり直し）

| ファイル | 更新タイミング | 中身 |
| --- | --- | --- |
| `training/state.json` | 毎回 | 学習中の重み・累計の反復回数 |
| `training/history.jsonl` | 毎回 1 行追記 | 実行ごとの記録（場所・回数・重み・チャンピオンへの勝率・昇格したか） |
| `training/champion.json` | 昇格時 | 現チャンピオンの重み |
| `training/champions/gen-NNNN.json` | 昇格時 | 世代ごとのスナップショット |

評価は「1 歩 = 10 点」を単位にしているので、重みはそのまま「何歩分の価値か」と読める。

GitHub Actions では Train ワークフローが 4 台並列で学習し、終わると次の回を自分で起動する。止めるときはリポジトリ変数 `TRAIN_CHAIN` を `off` にする。

## 実験

重い比較は Experiment ワークフローで Actions 上で回す（`scripts/experiments/` のスクリプトを実行し、結果は実行のサマリーに出る）。

```sh
gh workflow run Experiment -f script=compare -f args="--a '{\"wideRoot\":true}' --b '{\"wideRoot\":false}' --pairs 100"
```
